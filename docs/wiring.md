# คู่มือการต่อสาย VGA — TEST_VHA

ต่อจอ VGA เข้ากับบอร์ด **STM32 Nucleo-144 (STM32F767ZI)** โดยใช้ LTDC สร้างสัญญาณ VGA 640×480@60Hz

> ⚠️ อ่านส่วน **"ตัวต้านทานแปลงระดับสัญญาณ"** ก่อนต่อ — ถ้าต่อขา GPIO 3.3V เข้าจอ VGA ตรง ๆ โดยไม่มีตัวต้านทาน อาจทำให้พอร์ตจอเสียหาย

---

## 1. ภาพรวม

- จอ VGA รับสัญญาณสี R/G/B เป็น **แอนะล็อก 0–0.7V** ที่โหลด 75Ω
- STM32 ส่งออกเป็นดิจิทัล 3.3V → ต้องมี **ตัวต้านทานอนุกรม** ลดระดับแรงดันทุกช่องสี
- เฟิร์มแวร์ต่อ **เฉพาะบิตบนสุดของแต่ละช่องสี** (R7, G7, B7) → ได้ **8 สี** (เปิด/ปิด ต่อช่อง)
- HSYNC / VSYNC เป็นดิจิทัล **active-low** ต่อตรงเข้าจอได้เลย (ไม่ต้องมีตัวต้านทาน)

---

## 2. ขาที่ต้องต่อจริง (ขั้นต่ำ 5 เส้น + GND)

| สัญญาณจอ VGA | ขา STM32 | ขั้วต่อ VGA (DB15) | หมายเหตุ |
|---|---|---|---|
| RED    | **PE15** (LTDC_R7) | ขา 1  | ผ่านตัวต้านทานอนุกรม ~270–330Ω |
| GREEN  | **PD3**  (LTDC_G7) | ขา 2  | ผ่านตัวต้านทานอนุกรม ~270–330Ω |
| BLUE   | **PB9**  (LTDC_B7) | ขา 3  | ผ่านตัวต้านทานอนุกรม ~270–330Ω |
| HSYNC  | **PC6**  (LTDC_HSYNC) | ขา 13 | ต่อตรง (active-low) |
| VSYNC  | **PA4**  (LTDC_VSYNC) | ขา 14 | ต่อตรง (active-low) |
| GND    | GND ของบอร์ด | ขา 5,6,7,8,10 | กราวด์ร่วม — **ต้องต่อ** |

> หมายเหตุ: เฟิร์มแวร์ปัจจุบันใช้ palette 8 สี จึงต่อแค่ R7/G7/B7 ก็พอ
> ถ้าต้องการสีมากขึ้น (เช่น 64 สี / 256 สี) ต้องต่อบิตล่างเพิ่มผ่าน resistor ladder (ดูข้อ 5) และแก้ CLUT ใน `main.c`

---

## 3. ตัวต้านทานแปลงระดับสัญญาณ (สำคัญ)

จอ VGA = 0.7V สูงสุด ที่โหลดภายใน 75Ω ต่อกราวด์ ขา GPIO ส่ง 3.3V

ต้องมีตัวต้านทานอนุกรมบนสาย R, G, B เพื่อทำตัวหารแรงดันกับ 75Ω ในจอ:

```
GPIO 3.3V ──[ R_series ]──┬── ขาสีที่ขั้วต่อ VGA
                          │
                      (75Ω ภายในจอ)
                          │
                         GND
```

หา R_series ให้ได้ ~0.7V ที่ปลาย:

```
0.7V = 3.3V × 75 / (75 + R_series)
R_series ≈ 278Ω   →  ใช้ค่ามาตรฐาน 270Ω หรือ 330Ω
```

- **270Ω** → ~0.72V (สว่างกว่าหน่อย)
- **330Ω** → ~0.61V (ปลอดภัยกว่า)

ใส่ตัวต้านทาน **ช่องละ 1 ตัว** (รวม 3 ตัว) บน R, G, B
HSYNC / VSYNC **ไม่ต้องใส่**

---

## 4. ตำแหน่งขาบน Nucleo-144

ขา LTDC กระจายหลายพอร์ต ใช้ขาที่ต่อจริงตามนี้ (ดูซิลค์สกรีน CN บนบอร์ด):

- **PE15** → R7
- **PD3**  → G7
- **PB9**  → B7
- **PC6**  → HSYNC
- **PA4**  → VSYNC
- **GND**  → ขา GND ใด ๆ บน CN

เช็กเลขขา CN กับผังของ Nucleo-144 (UM1974) ก่อนเสียบจริง เพราะชื่อพอร์ตขา (PE15 ฯลฯ) ไม่ตรงกับเลขหมุด CN

---

## 5. ผัง LTDC ทั้งหมด (อ้างอิง — เผื่อขยายเป็น resistor ladder)

กำหนดใน `Core/Src/ltdc.c` → `HAL_LTDC_MspInit()` ทุกขาเป็น AF14 ยกเว้น PB0/PB1 เป็น AF9

| ขา | สัญญาณ | | ขา | สัญญาณ | | ขา | สัญญาณ |
|---|---|---|---|---|---|---|---|
| PG13 | R0 | | PE5  | G0 | | PE4  | B0 |
| PA2  | R1 | | PE6  | G1 | | PA10 | B1 |
| PA1  | R2 | | PA6  | G2 | | PC9  | B2 |
| PB0  | R3 (AF9) | | PE11 | G3 | | PD10 | B3 |
| PA5  | R4 | | PB10 | G4 | | PE12 | B4 |
| PC0  | R5 | | PB11 | G5 | | PA3  | B5 |
| PB1  | R6 (AF9) | | PC7  | G6 | | PB8  | B6 |
| PE15 | R7 | | PD3  | G7 | | PB9  | B7 |

| ขา | สัญญาณ |
|---|---|
| PE14 | CLK (pixel clock) |
| PF10 | DE (data enable) |
| PC6  | HSYNC |
| PA4  | VSYNC |

> ถ้าทำ resistor ladder (R-2R หรือถ่วงน้ำหนักบิต) ต้องต่อขา R0–R7 / G0–G7 / B0–B7 หลายบิตพร้อมปรับ CLUT และ `LTDC_PIXEL_FORMAT` ใน `VGA_Start()`

---

## 6. จับเวลา / สัญญาณนาฬิกา (อ้างอิง)

- โหมด: 640×480 @ 60Hz (VGA มาตรฐาน)
- Pixel clock: ~25.2MHz (จาก PLLSAI — `HAL_LTDC_MspInit`)
- HSYNC / VSYNC: active-low (`LTDC_HSPOLARITY_AL`, `LTDC_VSPOLARITY_AL`) — ตรงกับ VGA มาตรฐาน
- Timing ตั้งใน `MX_LTDC_Init()` (`ltdc.c`)

---
