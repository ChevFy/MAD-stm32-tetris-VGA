# CLAUDE.md

Guidance for Claude Code when working in this repository.

## Project

Bare-metal STM32 firmware that drives a **VGA monitor** from an STM32F767ZI (Nucleo-144) using the **LTDC** peripheral. The LTDC generates standard 640x480@60 VGA timing; RGB output is taken from only the **top bits of each color channel** through an external resistor DAC, so the usable palette is 8 colors. Comments in `Core/Src/main.c` are in Thai.

- MCU: STM32F767ZITx, Cortex-M7, 216 MHz (HSE bypass 8 MHz → PLL).
- Generated by STM32CubeMX; `.ioc` is the source of truth for pinout/clocks.
- Peripherals enabled: CORTEX_M7, LTDC, NVIC, RCC, SYS.

## Build

Toolchain: GNU Tools for STM32 (arm-none-eabi-gcc 14.3.rel1), normally via STM32CubeIDE.

Command-line build (from repo root):

```sh
make -C Debug all      # produces Debug/TEST_VHA.elf
make -C Debug clean
```

`Debug/makefile` and the `*.mk`/`subdir.mk` files are **auto-generated by the IDE — do not hand-edit them.** Regenerate by editing `TEST_VHA.ioc` in CubeMX/CubeIDE or by changing sources.

Linker script: `STM32F767ZITX_FLASH.ld` (flash target) / `STM32F767ZITX_RAM.ld`. Links with `--specs=nano.specs --specs=nosys.specs`, hard float (`fpv5-d16`).

Flash/debug: `TEST_VHA.launch` (ST-LINK / OpenOCD via CubeIDE).

## Layout

- `Core/Src/main.c` — entry point, `SystemClock_Config`, `MPU_Config`, and the VGA app code (`VGA_Start`, `VGA_TestPattern`, `VGA_Pixel`).
- `Core/Src/ltdc.c` — `MX_LTDC_Init` (VGA timing) + `HAL_LTDC_MspInit` (LTDC pin mux, PLLSAI clock).
- `Core/Src/gpio.c` — `MX_GPIO_Init`.
- `Core/Src/stm32f7xx_it.c` — interrupt handlers. `stm32f7xx_hal_msp.c` — HAL MSP.
- `Core/Inc/` — headers incl. `stm32f7xx_hal_conf.h` (HAL module enable), `main.h`.
- `Core/Startup/startup_stm32f767zitx.s` — vector table / reset.
- `Drivers/STM32F7xx_HAL_Driver`, `Drivers/CMSIS` — vendor HAL/CMSIS (do not modify).

## Editing rules

- **CubeMX round-trip:** CubeMX regenerates `Core/Src/*.c` and `ltdc.c`/`gpio.c` on `.ioc` changes. Put hand-written code **only between `/* USER CODE BEGIN x */` and `/* USER CODE END x */` markers** — anything outside is overwritten. The VGA code lives in `USER CODE BEGIN 2`, `USER CODE BEGIN 4`, and `PV`.
- Don't edit files under `Drivers/` or the auto-generated `Debug/` build files.

## How the display works (key facts)

- Framebuffer: `uint8_t framebuffer[640*480]` in `main.c`, 32-byte aligned, **L8 (8bpp indexed)** pixel format.
- CLUT maps index→color using only bits 2/1/0 → R/G/B (8 colors), matching the resistor-ladder wiring (top bit per channel).
- `MX_LTDC_Init` sets the 640x480 VGA timing; `VGA_Start` reconfigures layer 0 to L8 + the framebuffer and loads the CLUT. Note `main.c` sets layer 0 up again after `ltdc.c` configured two ARGB8888 layers.
- Pixel clock derives from PLLSAI (set in `HAL_LTDC_MspInit`, ~25.2 MHz target for VGA).
- `MPU_Config` runs before `HAL_Init`; LED on **PB7** blinks in the main loop as a liveness check tied to `LTDC->CPSR`.
